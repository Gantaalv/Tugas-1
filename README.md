2. Analisislah pada gambar kenapa saat instalasi perlu dipilih “/” pada opsi Mount Point ?
: Pada opsi Mount Point “/” dibutuhkan root sebagai filesystem yang berfungsi sebagai Lokasi penyimpanan utama atau folder utama untuk direktori penting seperti /etc, /usr, /var dan /home. Proses ini dilakukan agar sistem operasi memiliki direktori utama untuk menjalankan sistem

3. Berikan penjelasan tentang ext4, ext3, swap, ntfs, fat32,btrfs !
: Ext3 adalah File system Linux yang merupakan pendahulu EXT4. Keunggulan utamanya adalah memiliki fitur journaling, sehingga membantu menjaga data agar tidak mudah rusak ketika terjadi mati listrik atau system crash.

  Ext4 adalah bentuk terbaru dan lebih baik dari Ext3.

  SWAP Adalah ruang Cadangan yang diambil dari SSD/HDD dan digunakan sebagai memori virtual oleh Linux Ketika RAM tidak mencukupi

  NTFS (New Technology File System) File yang umumnya digunakan oleh Windows yang dikembangkan sendiri oleh Microsoft, yang mendukung file berukuran besar, permission dan journaling.

  FAT32 (File Allocation Table 32) File system yang kompatable ke Linux, Windows, MacOS lebih simple dari NTFS namun memiliki Batasan 4GB per file 

  BTRFS (B-tree File System) File system Linux modern yang menyediakan fitur seperti snapshot, compression, checksumming, dan subvolume. Cocok untuk sistem yang membutuhkan pengelolaan data dan fitur pemulihan yang lebih canggih.
